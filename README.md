# Single-Microcontroller-Split-Keyboard-SMCK
Design for a split keyboard that only uses a singular microcontroller, passive side uses a cascade of shift registors to send data through a singular serial wire leaving the 2 sides connected by only 5 wires (GND, VCC, CLK, PL, DATA)
